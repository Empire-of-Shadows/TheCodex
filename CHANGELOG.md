# Changelog

All notable changes to TheCodex will be documented in this file.

**The contents of this file should never be overwritten.**

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased] - 2026-06-08

### Changed
- The public **Privacy Policy** is now clearer and more accurate: it explains that TheCodex reads message content and stores the text of your suggestions and Would-You-Rather entries (with their votes), and lists the other things it keeps — the member whitelist, server-boost records, a cached copy of your server's members, roles and channels, and usage analytics. The contact address is **support@eosofficial.club**.

## [Unreleased] - 2026-06-03

### Changed
- The dashboard now has the same three pages as the other Empire of Shadows bots: **Stats**, **Privacy**, and **Settings**. The old separate "Admin" and "Mod" areas are now one **Settings** page — it shows up if you can manage a server (Manage Server permission or a configured admin/mod role). The guide Builder still lives inside Settings for admins.
- When you pick a server the bot isn't in yet, you now get a clear "Invite TheCodex" link to click instead of a pop-up window opening on its own.

## [Unreleased] - 2026-05-30

### Added
- Started keeping this changelog so community members can see what's new, changed, and fixed in TheCodex.
